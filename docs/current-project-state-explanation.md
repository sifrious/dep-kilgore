# Current Project State Explanation (K19 slice)

Kilgore explains why a project is in its current state by composing cited historical state comparison with timeline interpretation.

## Contract

- Scope is an opaque project `funes_ref`, never path identity.
- State comparison uses explicit temporal baselines.
- Timeline reasoning uses explicit period boundaries.
- Observations and inferences remain typed and distinct.
- Contradictions are explicit, cited, and visible.
- Completeness and uncertainty remain first-class and unsuppressible.

## Reasoning layers

1. Retrieve evidence before interpretation for baseline/current state and timeline period.
2. Derive current-versus-prior changes.
3. Add temporal context from project timeline groups.
4. Produce explicit inferences and contradiction signals with provenance citations.

Path/location/SHA are contextual metadata only and never identity.
