# Left-Off Context (K21 slice)

Kilgore answers “what was I doing when I left off?” from bounded project history.

## Contract

- Retrieval occurs before interpretation.
- Last confirmed work boundary is explicitly detected from timeline evidence.
- Active work episode reconstruction keeps observations separate from inferences.
- Ranked evidence remains citation-linked to Funes refs.
- Unresolved context (missing evidence and unresolved inferences) is explicit.
- Completeness and uncertainty remain first-class and unsuppressible.

## Output semantics

- `lastConfirmedEpisode`: the most recent confirmed observation-boundary in the bounded history.
- `rankedEvidence`: supporting events ranked by recency, layer, and citation presence.
- `unresolvedContext`: unresolved interpretation and missing expected evidence extracted for safe resumption.

Path/location/SHA are contextual metadata only and never identity.
